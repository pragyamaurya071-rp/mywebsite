⚡ Kirchhoff’s Voltage Law (KVL)

📌 Definition

According to KVL, in any closed circuit loop, the sum of all voltages is equal to zero.

📌 Statement

The algebraic sum of all voltages in a closed loop is zero.

📌 Formula

V₁ + V₂ + V₃ + ... = 0

📌 Explanation

  • Voltage rise = Voltage drop
  • Used in circuit analysis
  • Important for solving loop circuits

📌 Uses

  • Electrical circuit solving
  • Loop current analysis
